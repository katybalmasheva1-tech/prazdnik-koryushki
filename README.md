# Праздник корюшки — сайт фестиваля

Статический адаптивный лендинг на HTML, CSS и JavaScript. Не требует сборки, npm или сервера.

## Публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `prazdnik-koryushki`.
2. Загрузите в корень репозитория файл `index.html` (можно через **Add file → Upload files**).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В Branch выберите **main** и папку **/(root)**, затем нажмите **Save**.
6. Подождите 1–3 минуты. Ссылка появится вверху раздела Pages и будет иметь вид:
   `https://ВАШ-ЛОГИН.github.io/prazdnik-koryushki/`

## Важно
Тексты о программе, датах и билетах отражают предоставленный бриф. Карта площадки — условная иллюстрация, не точный план. Реальные ссылки на билетного оператора и соцсети организаторов не предоставлены.
